Compile prompt templates into typed TypeScript functions so the compiler catches mismatched placeholders before runtime.

```ts
type PromptTemplate<T extends Record<string, string>> = (vars: T) => string;

function compile<T extends Record<string, string>>(template: string): PromptTemplate<T> {
  return (vars) => template.replace(/\{\{(\w+)\}\}/g, (_, key) => vars[key] ?? "");
}

const systemPrompt = compile<{ role: string; task: string }>(
  "You are a {{role}}. Your task: {{task}}"
);

systemPrompt({ role: "code reviewer", task: "find security issues" });
// "You are a code reviewer. Your task: find security issues"
```

- The template function signature is derived from the placeholders so missing or extra keys are type errors.
- String replacement is deterministic and allocation-light compared to full templating engines.
- Works with any LLM provider that accepts plain text prompts.
