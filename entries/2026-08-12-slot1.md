Stream structured tool results to the client as typed events instead of buffering the entire response. This lets the UI render progress incrementally and keeps memory bounded for long-running agent loops.

```typescript
type ToolEvent =
  | { type: "tool_start"; tool: string; args: Record<string, unknown> }
  | { type: "tool_delta"; tool: string; delta: string }
  | { type: "tool_end"; tool: string; result: unknown };

async function* runAgent(input: string, signal: AbortSignal): AsyncGenerator<ToolEvent> {
  const tools = await planTools(input);
  for (const tool of tools) {
    yield { type: "tool_start", tool: tool.name, args: tool.args };
    const stream = executeToolStream(tool.name, tool.args, signal);
    for await (const delta of stream) {
      yield { type: "tool_delta", tool: tool.name, delta };
    }
    const result = await stream.final();
    yield { type: "tool_end", tool: tool.name, result };
  }
}
```

- Typed discriminated unions let the client handle each event variant exhaustively without string matching.
- Async generators with AbortSignal propagate cancellation cleanly through the whole chain.
- The client can render tool_start immediately, stream tool_delta tokens, and commit tool_end without waiting for the full loop.
