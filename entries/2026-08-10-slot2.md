Offload CPU-bound work in async agent loops to a dedicated thread pool so the event loop stays responsive. Blocking the loop with JSON serialization, embedding computation, or crypto slows every concurrent request.

```python
import asyncio
from concurrent.futures import ThreadPoolExecutor
from functools import partial

cpu_pool = ThreadPoolExecutor(max_workers=4, thread_name_prefix="cpu-bound")

async def run_cpu_bound(fn, *args, **kwargs):
    loop = asyncio.get_running_loop()
    return await loop.run_in_executor(cpu_pool, partial(fn, *args, **kwargs))

async def agent_step(state: AgentState) -> AgentState:
    embedding = await run_cpu_bound(compute_embedding, state.query)
    result = await run_cpu_bound(heavy_json_transform, embedding)
    return state.model_copy(update={"result": result})
```

- Keep the async loop free for I/O (LLM calls, DB, HTTP) by moving compute to threads.
- Size the pool to your CPU cores; too many threads adds contention without throughput.
- Name threads so profiling and logs show where time is spent.
