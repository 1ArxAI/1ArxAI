# Structured concurrency with task groups prevents leaked agent tasks

When an agent spawns multiple concurrent operations (tool calls, sub-agents, API requests), a single failure or cancellation should tear down the rest. Python `asyncio.TaskGroup` and `anyio.create_task_group` enforce this: if any child raises, the group cancels all siblings and re-raises the first exception. No orphaned tasks, no silent resource leaks.

```python
import asyncio

async def run_agent_step(ctx: AgentContext) -> StepResult:
    async with asyncio.TaskGroup() as tg:
        fetch_tools = tg.create_task(ctx.registry.list_tools())
        fetch_memory = tg.create_task(ctx.memory.read(ctx.session_id))
        fetch_policy = tg.create_task(ctx.policy.load())

    tools, memory, policy = fetch_tools.result(), fetch_memory.result(), fetch_policy.result()
    return await ctx.planner.plan(tools, memory, policy)
```

- Task groups guarantee all-or-nothing completion so a timeout or error in one branch cannot leave background work running
- Explicit `await` on `result()` surfaces the real exception instead of swallowing it in a done callback
- Prefer `TaskGroup` over `gather` when any failure should cancel the whole unit of work
