Validate structured LLM output with a strict schema gate and retry on failure so bad data never reaches your database.

```python
from pydantic import BaseModel, ValidationError
from tenacity import retry, stop_after_attempt, wait_exponential_jitter

class AgentOutput(BaseModel):
    action: str
    params: dict
    confidence: float

@retry(
    wait=wait_exponential_jitter(initial=0.5, max=4),
    stop=stop_after_attempt(3),
    retry=lambda e: isinstance(e, ValidationError),
)
def call_llm_with_schema(prompt: str) -> AgentOutput:
    raw = llm_client.complete(prompt)
    return AgentOutput.model_validate_json(raw)
```

- A schema gate catches hallucinated fields and type mismatches before they propagate
- Exponential-jitter retries let the model self-correct without hammering the provider
- Store the raw response alongside the parsed object so evals can measure parsing drift
