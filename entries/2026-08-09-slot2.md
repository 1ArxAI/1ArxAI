Prompt versioning with git-style diffs catches regressions before deploy. Store every prompt template asdasdasd in a prompts/ folder with semantic version tags, and diff rendered prompts in CI to surface unintended changes before they hit production.

```python
# prompts/agent_system/v1.2.0.md
---
version: "1.2.0"
model: "gpt-4o"
temperature: 0.2
---
You are a precise coding agent. Follow the user's instructions exactly.
Prefer vanilla TypeScript. No external deps unless requested.
```

```bash
# CI step: diff rendered prompts against main
git diff main..HEAD -- prompts/
# If changes detected, run eval suite before merge
pytest evals/prompt_regression.py
```

- Treat prompts as code: version, review, and test them like any other artifact.
- Diff the fully rendered prompt (template + variables) in CI, not just the template file.
- Pair with an eval harness that runs on every PR to catch behavioral regressions automatically.
